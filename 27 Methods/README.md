# Methods

本目录保存值得跨概念复用的证明方法、构造方法和计算方法。

Method 页不以“定义一个新对象”为目标，而以“给定一类问题，如何系统地得到结论”为目标。

典型候选包括：反证法、对角线法、能量估计、由约束 Jacobian 求切空间、坐标化计算、局部到全局拼接等。
